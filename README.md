#  Problem Solving Archive

알고리즘 문제 풀이와 코딩 공부 흔적을 기록하는 개인 저장소입니다. 
배운 내용을 복습하고, 코딩 테스트를 대비하기 위해 꾸준히 문제 풀이를 진행하고 있습니다.

현재 아래 플랫폼들의 문제들을 풀고 연동하여 기록하고 있습니다.

* **[Programmers (프로그래머스)](https://programmers.co.kr/)**
* **[SWEA (SW Expert Academy)](https://swexpertacademy.com/)**
* **[goormlevel (구름레벨)](https://level.goorm.io/)**

##  Languages & Tech Stack
주로 사용하는 언어는 다음과 같습니다.
- **Python**: 메인으로 학습하며 문제 풀이에 적극 활용 중입니다.
- **C / C++**: 자료구조와 알고리즘의 기초를 다지기 위해 사용합니다.
